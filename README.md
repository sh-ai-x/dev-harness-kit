## 무엇

- **Plan+Design 자동화**: `/dev-kit:plan` 한 커맨드로 PRD.md + phases/<name>/step<N>.md 자동 생성 (pm-prd-fast + interview-harness 통합).
- **Build 단계별 sub-agent 위임**: harness-runner engine + TDD + 자동 수정 루프.
- **Review/Security fan-out**: 3-dim (correctness + security + architecture) + 10-dim OWASP A01–A10, 단일 메시지 병렬.
- **Eval-Repair 8단계 loop**: 자산 신선도 자동 점검 + Specialized Fixer + 마지막 = Human Review.
- **Hot-on-the-Loop 자동 + 마지막 사용자 approve**: 응답 피로도 0.

## 설치 (plugin-only)

`commands/` 방식은 더 이상 사용하지 않습니다 — **plugin만** 씁니다.

```bash
# marketplace install (권장)
claude plugin marketplace add sh-ai-x/dev-harness-kit
claude plugin install dev-kit

# 또는 local checkout
git clone https://github.com/sh-ai-x/dev-harness-kit
# marketplace가 디렉토리 소스로 자동 인식 → reload
claude plugin marketplace add ./dev-harness-kit
claude plugin install dev-kit

# 이후 세션 시작마다
/reload-plugins
```

## 사용 (0-arg, namespaced)

```
/dev-kit:bootstrap              # 첫 진입 (CLAUDE.md 자동 생성)
/dev-kit:plan                    # PRD + phases 자동 (Plan+Design 통합)
/dev-kit:build                   # 단계별 sub-agent 실행
/dev-kit:review                  # 3-dim 코드 리뷰 (correctness + security + architecture)
/dev-kit:security                # 10-dim OWASP A01–A10
/dev-kit:audit                   # slop + secret 일괄 감사
/dev-kit:eval                    # 자산 신선도 평가
/dev-kit:repair approve|reject|defer <asset>   # Eval-Repair Human Review
/dev-kit:ship                    # release tag

# Shortcuts (긴급 핫픽스)
/dev-kit:tdd-fast                # Bootstrap+Plan 우회 → Build 직행
/dev-kit:quick-fix               # verify+debug 즉시 호출
```

전체 27개: `/<skill-name>` 또는 `dev-kit:<skill-name>`로 invoke.

## 설계 원칙 (ADR-0011~22)

- **NO-DUP**: Iron Law 1곳 (CLAUDE.md §1). 2-layer verification (hook + skill).
- **NO-BOTTLENECK**: 0-arg UX. Lazy CLAUDE.md. Sub-agent 병렬.
- **NO-MEANINGLESS-LOOP**: 5필드 loop 의미 보장 + 자동 STOP + user interrupt.
- **HOTL (MUST-29)**: 자동 진행 + 사용자 supervisor + interrupt 1회.
- **Methodology 확장 (MUST-48)**: TDD/SDD/DDD/BDD/FDD 선택 가능.
- **A2A typed (MUST-39)**: Sub-agent ↔ main JSON Schema SSOT.
- **Plugin-only (v0.1.0+)**: `.claude/skills/`, `commands/`, `install.sh` 전부 제거. plugin manifest가 SSOT.
