Phase 1 — Local pre-push hook (issue-sync only)

Goal: hooks/pre-push.sh runs only the issue-sync stage. Local CPU/memory footprint: <10MB RSS, ~9s wall-clock. Provider tokens saved per caught stale-ref push: $1-3 (the PR #829 failure mode).

Branch-policy and cost-flag are not in this hook:

  • branch-policy already enforced by hooks/git-guard.sh.
  • cost-flag doesn't save tokens (just adds a PR label).
