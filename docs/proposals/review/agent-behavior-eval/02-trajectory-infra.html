개요

모든 trajectory 데이터는 worktree 내 JSON 파일에 저장. 외부 telemetry 인프라 없음. 한 줄 요약:

worktree/<task>/
├── .git/                         # git history (이미 존재)
├── hooks-output.log              # hook firing log (이미 존재)
├── .dev-kit/hand-off/*.md        # 단계 노트 (이미 존재)
└── eval/transcripts/
    └── <case-id>/
        └── <UTC-timestamp>.json  # ← 본 proposal 신규

TraceLog API

# lib/trace_log.py
from dataclasses import dataclass, field, asdict
from pathlib import Path
from datetime import datetime, timezone
from typing import List, Optional
import json

@dataclass(frozen=True)
class TraceStep:
    ts: str                              # ISO-8601 UTC
    skill: str
    phase: str
    model: Optional[str] = None
    prompt_hash: Optional[str] = None
    input_tokens: int = 0
    output_tokens: int = 0
    latency_ms: int = 0
    retries: int = 0
    exit_code: int = 0
    extra: dict = field(default_factory=dict)

@dataclass(frozen=True)
class TraceLog:
    schema_version: int = 1
    case_id: str = ""
    started_at: str = ""
    ended_at: str = ""
    harness_version: str = ""
    agent: str = ""
    worktree_branch: str = ""
    worktree_path: str = ""
    steps: List[TraceStep] = field(default_factory=list)
    judge_scores: List[dict] = field(default_factory=list)
    evidence: dict = field(default_factory=dict)

    def to_dict(self) -> dict:
        d = asdict(self)
        d["steps"] = [asdict(s) for s in self.steps]
        return d

    @classmethod
    def load(cls, path: Path) -> "TraceLog":
        raw = json.loads(path.read_text())
        steps = [TraceStep(**s) for s in raw.pop("steps", [])]
        return cls(steps=steps, **raw)

    def save(self, worktree: Path) -> Path:
        ts = datetime.now(timezone.utc).strftime("%Y%m%dT%H%M%SZ")
        out_dir = worktree / "eval" / "transcripts" / self.case_id
        out_dir.mkdir(parents=True, exist_ok=True)
        out = out_dir / f"{ts}.json"
        out.write_text(json.dumps(self.to_dict(), indent=2))
        return out

Diff 도구 (tools/trace_diff.py)

사용법: python -m tools.trace_diff baseline.json current.json

출력 (구조화):

Trace diff: baseline.json -> current.json
─────────────────────────────────────────
Step count:    8 -> 11         (+3)
Total tokens:  4.2k -> 6.8k   (+2.6k, +62%)
Total latency: 12.3s -> 18.9s (+6.6s, +54%)
Retry total:   1 -> 4         (+3)  ⚠️
─────────────────────────────────────────
Per-axis score delta:
  D1_outcome        5 -> 5   (=)
  D2_process        4 -> 3   (-1)  ⚠️
  D3_efficiency     4 -> 3   (-1)  ⚠️
  D4_safety         5 -> 5   (=)
  D5_communication  4 -> 4   (=)
  D7_trajectory     4 -> 3   (-1)  ⚠️
─────────────────────────────────────────
Verdict: OK -> DRIFT_WARNING  ⚠️
─────────────────────────────────────────
Exit 1 (delta > threshold)

임계값 (delta 가 다음 초과 시 exit 1):

  • retry count > +2
  • tokens > +50%
  • latency > +50%
  • per-axis score drop > 1
  • verdict drop (OK → DRIFT/ROT/ESCALATED)

Cost Dashboard (tools/cost_dashboard.py)

사용법: python -m tools.cost_dashboard eval/transcripts/ > cost.html

표시 항목 (정적 HTML, JS 없음):

  • $/case — case 별 누적 API 비용
  • $/judge — judge 호출당 비용
  • Top-10 expensive prompts — 비용이 큰 prompt 상위 10개
  • Latency p50/p95 — step 별 지연 분포
  • Token 분포 — input/output 비율
  • Trend (D1 future) — 1 주 단위 평균

색상 토큰: design.md 의 --accent, --bg, --card-bg 등 재사용.

신규 의존성 (0)

본 인프라에 신규 의존성 없음. 모두 표준 라이브러리:

  • dataclasses — trace / step 구조
  • json — 직렬화
  • pathlib — 파일 경로
  • subprocess — git / pytest / lint 호출
  • argparse — CLI
  • html (stdlib) — dashboard escape

LLM judge (D5/D7) 는 기존 lib/llm_judge.py:call_judge() 재사용.
