This page is a read-only mirror of a running bin/babysit-pr-local.sh session. It follows .dev-kit/babysit-pr-local-live.log via the server's /tail SSE route and never spawns bin/review-local.sh. There is intentionally no Start / Stop button — clicking one would spawn a duplicate verdict pipeline (and a second round of claude -p API spend) alongside the babysit session already running. To run a one-shot local review manually, use bin/review-local.sh --pr N from a terminal instead.
