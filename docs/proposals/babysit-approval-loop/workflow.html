babysit-pr · Code-review optimized workflow

Healthy PRs follow a short path. RCA, context reset, and model escalation are recovery lanes—not mandatory review stages.

Optimization: one fresh snapshot → one targeted blocker → one bounded fix → focused verification → one push → wait for external evidence.

개선은 이 안전망을 제거하지 않고, 건강한 경로에서 불필요한 분석만 생략한다.

1. Normal code-review path

정상 경로에는 full RCA ledger나 별도 model debate를 넣지 않는다. 변경된 blocker만 처리한다.

2. Escalation lane (필요할 때만)

Escalation은 blocker가 실제로 정보 부족·모순·정책 문제일 때만 실행한다.

3. Durable wait / approval gate

review-required는 성공도 실패도 아닌 정상적인 durable wait 상태다.
