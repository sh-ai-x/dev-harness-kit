# Refactor — inspect 2026-08-27 follow-up

Resolves 11 of 28 HIGH-severity findings from the
`/dev-kit:inspect` sweep on 2026-08-27. Full sweep report lives at
`.dev-kit/inspect-report.md` in the worktree; this file documents the
11 mechanical + small-structural fixes that landed in PR #755 and the
17 deferred items.

## What changed

- **`lib/dual_import.py`** (new) — `from_dual(module, names)` /
  `from_dual_optional(...)` helpers collapse the
  `try: from .X import ... except ImportError: from X import ...`
  dance that `ci_setup / ci_doctor / ci_update` used to hand-copy four
  times. Used by `ci_doctor.py` and `ci_update.py` (in-package callers
  only — `ci_setup.py` is shipped flat to consumers and keeps its
  inline pattern). (dup-5)
- **`lib/gh_cli.py`** (new) — `gh_available(timeout=...)` collapses the
  `shutil.which('gh') + subprocess.run([gh, 'auth',
  'status'], timeout=...)` block that five sites used to repeat. Used
  by `ci_doctor.py` (4 sites) + `ci_setup.py` (1 site, with a local
  re-implementation for the consumer-install path). (dup-6)
- **`lib/behavior_scorers/_git_helper.py`** (new) — shared
  `git_output(worktree, *args, timeout=30)` wrapper. Replaces the
  byte-identical `_git_output` function that `process.py` and
  `safety.py` each defined. (dup-2)
- **`lib/behavior_scorers/types.py`** — added `empty_scorer(dim_id,
  reason, phase)` factory. D6 robustness now imports `score =
  empty_scorer(...)`; D5 communication keeps its custom body for the
  extra `context_no_llm` flag. (dup-3)
- **`lib/behavior_scorers/trajectory.py`** — split
  `_load_latest_trace` into `_latest_trace_path(worktree) -> Path |
  None` + `_load_latest_trace`. D3 efficiency now imports the path
  helper, so the eval/transcripts layout lives in one place. (dup-4)
- **`lib/eval_runner.py`** — deleted the local `_coerce_score` def and
  imported the canonical one from `lib.eval._coerce_score`. (dup-1,
  CRITICAL)
- **`lib/behavior_scorers/registry.py`** — deleted (zero importers;
  SCORER_REGISTRY is built statically in `__init__.py`). (overeng-1)
- **`lib/dispatch_classifier.py`** — `_has_overlap` pre-normalizes each
  step's `writes` once (O(N)) instead of recomputing inside the inner
  (i,j) loop (O(N²)). (overeng-3)
- **`lib/active_hooks_codec.py`** — `load_matrix` memoizes per
  `(path, mtime)`; cache evicted at 32 entries. `stage-gate.sh` pays
  one disk read per mtime change instead of one per call. (overeng-4)
- **`lib/analysis_core/__init__.py`** — re-exports `mask_secrets` (the
  public alias for `runner._mask_secrets`). `verify_harness.py` now
  imports the public alias. (overarch-1)
- **`lib/git_worktree.py`** — added public `branch_exists` alias
  (and `__all__` export). `acp_dispatch.py` imports the public alias.
  (overarch-2)
- **`lib/pr_verify.py`** — introduced `PrVerifyContext` dataclass
  (pr_number, repo, fetched_at, comments, pr_pushed_at, pr_head_sha).
  All 5 gates (G1–G5) take `ctx: PrVerifyContext` instead of 3–6
  positional args. 36 test call sites in `tests/test_pr_verify.py`
  updated. (smell-22)
