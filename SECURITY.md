# Security Policy

## Supported versions

Security fixes are made against the latest release on `main`.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue. Email the
maintainer at the address listed in the repository's GitHub security contact,
or use GitHub's private vulnerability reporting for this repository.

Include the affected version or commit, reproduction steps, impact, and any
suggested mitigation. We will acknowledge reports as soon as practical and
coordinate a fix and disclosure timeline with the reporter.
